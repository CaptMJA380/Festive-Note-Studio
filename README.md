# 🪔 Festive Notes Studio

**B2B Personalised Diwali Greeting Cards for Corporate Gifting Companies & Hamper Suppliers in Pune, Maharashtra, India.**

Festive Notes Studio partners with corporate hamper makers and gifting companies, allowing them to offer bespoke personalised greeting cards as a thoughtful add-on to their existing Diwali gift hampers—without adding graphic design or recipient-formatting overhead to their internal team.

---

## 🏛️ Core Concept: Diwali Through India's Heritage

Our unique selling proposition is that **every greeting card celebrates Diwali through the architecture, monuments, palaces, and cultural heritage of India**. 

Instead of generic clip-art, each design features an authentic Indian monument artistically integrated into a single-sided A6 flat greeting card (105 × 148 mm portrait) with natural Diwali elements: glowing brass diyas, warm candlelight reflections, jasmine and marigold florals, and subtle ornamental borders.

## ⚙️ Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev
# The website will be live at http://localhost:5173/

# 3. Production build
npm run build

# 4. Preview production build
npm run preview
```
